# Petroxella site
`npm i && npm run dev`. Set `VITE_FORM_ENDPOINT` (see .env.example) to enable inquiry delivery.
All content lives in `src/data/content.ts`. Drop client photos into `public/img` and set `src` paths (Img shows labelled placeholders until then).
Replace `petroxella.com` in index.html, robots.txt, sitemap.xml with the confirmed domain. SPA hosting needs a fallback to index.html.
